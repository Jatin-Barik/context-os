# Contribution Guide

## Principles

- Keep changes focused and reviewable.
- Preserve local-first defaults.
- Avoid duplicating logic across features.
- Favor typed contracts and explicit interfaces.

## Before you submit

- Run the build.
- Run the tests.
- Verify the UI still opens with `Ctrl + Space`.
- Update docs if the behavior changed.

## Commit hygiene

- Use descriptive commit messages.
- Keep feature slices small.
- Separate refactors from behavior changes when possible.
