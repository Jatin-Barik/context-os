# Installation Guide

## Prerequisites

- Node.js 20 or newer
- npm 10 or newer
- Windows 10 or newer for the current local development setup

## Install

```bash
npm install
```

## Run in development

```bash
npm run dev
```

## Build for production

```bash
npm run build
```

## Test

```bash
npm run test
```

## Notes

- The app is configured for a local Electron + React development loop.
- Core AI and desktop integrations are not yet wired in; the current state is the shell and palette foundation.
