# Demo Script

1. Launch the app.
2. Press `Ctrl + Space`.
3. Type `summarize`.
4. Execute the command.
5. Open the History page and show the generated action.
6. Open the Memory page and explain the local-first storage plan.
7. Open Settings and point to the privacy controls.

## Demo goals

- Show the floating palette interaction.
- Show local state persistence.
- Show the feature-based shell structure.
- Explain the next steps for screen understanding and local inference.
